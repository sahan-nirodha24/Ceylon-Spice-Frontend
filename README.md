# Ceylon Spice - Premium Sri Lankan Restaurant 🍲🇱🇰

![Ceylon Spice Restaurant](images/hero-1.jpg)

## 📌 Overview
**Ceylon Spice** is a modern, premium frontend web template designed for a high-end Sri Lankan restaurant. This project was built as a web development assignment to showcase clean, human-readable code, responsive UI/UX, and an engaging digital dining experience without relying on heavy frameworks. 

## ✨ Key Features
- **Modern & Premium UI:** Crafted to deliver a luxurious feel with high-quality imagery, smooth hover effects, and typography.
- **Dynamic Menu Filtering:** "Signature Menu" featuring smooth cascading animations and tabbed categories (Local Favorites, Main Course, Desserts).
- **Interactive Grid/List Toggle:** Allows users to view the menu as a visual photo grid or a classic text-based restaurant list.
- **Scroll Reveal Animations:** Elements elegantly fade and slide into view as the user scrolls down the page.
- **Ingredient Hover Descriptions:** Interactive overlay on all dish images revealing mouth-watering ingredient details.
- **100% Fully Responsive:** Looks perfect on desktops, tablets, and mobile devices.

## 🛠️ Technologies Used
- **HTML5:** Semantic and highly structured markup.
- **CSS3:** Custom styles, Flexbox/Grid layouts, and CSS animations.
- **Vanilla JavaScript:** For lightweight DOM manipulation (Grid/List toggle, Intersection Observer for scroll animations).
- **Bootstrap 5.3.3:** The absolute latest stable version for rapid, responsive UI components.
- **FontAwesome 6:** For beautiful, scalable vector icons.

## 🚀 Getting Started

This is a pure frontend application with no backend or database dependencies.

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Ceylon-Spice-Frontend.git
   ```
2. Navigate to the project folder.
3. Simply double-click `index.html` to open it in your browser, or use a tool like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for a better development experience.

### Hosting on Vercel
Since there are no build steps or environment variables required, deploying to Vercel is incredibly fast:
1. Push this repository to your GitHub account.
2. Log in to [Vercel](https://vercel.com/) and click **Add New > Project**.
3. Import your GitHub repository.
4. Leave the build settings as default (Root directory) and click **Deploy**.
5. Your site will be live in seconds!
